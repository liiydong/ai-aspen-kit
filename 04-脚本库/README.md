# 脚本库说明

本目录收录了「AI 做 Aspen」全过程中实际写过的 Python 脚本，是**方法的物证**——
每个脚本都对应一次真实的排查、尝试或验证。按前缀可快速定位用途。

## 命名约定

| 前缀 | 含义 | 典型用途 |
|---|---|---|
| `dump_*` | 导出/探查 | 把 bkp 段、COM 字段树、模块参数导出成文本，看"里面到底有什么" |
| `chk_*` / `check_*` | 校验 | 核对参数是否落库、物料是否平衡、结果是否与预期一致 |
| `cmp_*` | 对比 | 两个 bkp / 两组结果的逐项差异 |
| `diag_*` | 诊断 | 针对某个异常（不收敛、温度异常、组分缺失）做定向排查 |
| `test_*` | 受控实验 | 一次只改一个变量，验证某个假设（如"写 NPHASE 会不会消警告"） |
| `fix_*` / `apply_*` | 施加变更 | 把确定的修改写回模型 |
| `gen_*` | 生成 | 由计算结果生成 Excel / Word / 图表 |
| `collect_*` | 汇总 | 把散落在多处的数据收集成一张表 |
| `parse_*` | 解析 | 解析 Aspen 报告文本/TSV 为结构化数据 |
| `probe_*` / `explore_*` | 探路 | 不确定 API/字段时的试探脚本 |

## 本包中最值得先看的几个

| 脚本 | 为什么重要 |
|---|---|
| `parse_report.py` | **Aspen xlsx 报告解析器**：处理三列切分、数值粘连、分页识别。核对论文数据的起点 |
| `parse_blocks.py` | 提取 36 个模块的关键结果（塔板数、回流比、冷凝/再沸负荷、塔顶塔底温度） |
| `metrics.py` | 由解析结果重算全部工程指标（单耗、收率、产汽量、换热负荷） |
| `dump_cols.py` | 把 xlsx 按 A/B/C 三列原样导出为 TSV，是上面解析器的前置步骤 |
| `build_kit.py` | 构建本封装包的脚本本身 |

## 使用提醒

1. **环境不同**：这些脚本里有大量硬编码的绝对路径（`D:\<化工工作区>\...`、`C:\Users\<用户名>\...`），
   移植时需先替换路径。
2. **多为一次性工具**：写的时候以"这一轮排查够用"为目标，缺少参数化与错误处理。
   若要长期复用，建议按功能归类、补 docstring、抽出公共模块。
3. **COM 脚本耗时**：凡 `win32com` 打开模型的脚本，单次运行 3–10 分钟，请后台执行。
4. **两个 Python 环境**：
   - COM 脚本 → `D:\<化工运行时>\python-env\Scripts\python.exe`
   - 表格/文档处理 → `D:\<Python3.10>\python.exe`（含 openpyxl / python-docx）
