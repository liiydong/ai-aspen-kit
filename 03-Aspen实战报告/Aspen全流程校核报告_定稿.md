## 四、关键校核结论

1. **三效蒸发热集成成立**：一效二次蒸汽（100 ℃）作二效（0.47 bar / 80 ℃）热源，二效作三效（0.20 bar / 60 ℃）热源，三效二次蒸汽进冷凝器，温压梯度自洽。
2. **结晶母液 40.3 wt%** 与 5 ℃ 溶解度数据吻合；92% 循环 + 8% 排放使精制段收率锁定在 **96.5%**（收率链取 0.97，安全侧）。
3. **产品规格达标**：99.62% 含量（≥99.5%）、0.28% 水分（≤0.5%）、3-CP 0.11%。
4. **3-MP 单耗 910.7 kg/t** 比设计值低 2.8%——关键在于把 T-402 轻组分中的未反应 3-MP 经 M-504 回收返回反应器，以及把 T-404 采出比由 0.95 提高到 0.99（塔釜 3-CP 损失由 63.7 降到 12.7 kg/h）。

## 六、Aspen COM 自动化的软件边界（供复现）

1. `.apwz` 封装格式 COM **打不开**，需解出内部 `.bkp`；
2. **流股 TEMP / PRES 不能用 COM 写**（返回 `AE_UNDERSPEC`），只能文本注入；模块参数与组分流量可以写；
3. bkp 段落记录分隔符必须**单个 `\`**，且按 **76 字符折行**，否则 Aspen 只解析前几条；
4. **段头也会被折行拆开**（如 `? STREAM` / `MATERIAL` 分行），定位段必须用容忍换行的正则，不能用 `find`；
5. Flash2 端口：**M0-1 = 气相 V、M1-2 = 液相 L**；RadFrac：M0-1 = VD、M1-2 = LD、M2-3 = B；Sep 只有一个产品口；
6. 新增/改块类型必须**同步文件头的块实例注册表**（`>VERSION 0 / 块名 / 模型 / Built-In / 类型`）与 `NumLibs` 前的计数；
7. NRTL 二元参数需在参数段补 `BDBANK` 检索清单才会自动检索；
8. 报错只能用 `Engine.Run2` + `OnControlPanelMessage` 事件钩子捕获（`ControlPanel` 属性在本机不可用）；
9. **物料平衡核对时不要把自己设的循环流计入出料**（本次曾因此误判 0.53% 偏差）。
