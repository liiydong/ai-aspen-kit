## 三、为什么必须补 4-甲基吡啶

工艺流程里，**4-氰基吡啶（4-CP）** 这个杂质不是凭空来的——它是原料 3-甲基吡啶里混的 **4-甲基吡啶** 氧化后的产物：

```
主反应： 3-甲基吡啶 + NH₃ + 1.5 O₂ → 3-氰基吡啶 + 3 H₂O
副反应： 4-甲基吡啶 + NH₃ + 1.5 O₂ → 4-氰基吡啶 + 3 H₂O   ← 需要 4-甲基吡啶
```

而 **T-403 脱 4-CP 塔**（相对挥发度只有 1.05、理论板 45、回流比 15~20）就是全流程最难分离的一段。**没有 4-甲基吡啶，R-101 里就生成不出 4-氰基吡啶，T-403 这一段就模拟不出来**，论文里那部分也就没法自圆其说。

> 找不到时，直接在 `组分 ID` 格里输英文名 **`4-METHYLPYRIDINE`** 也能搜到。

## 四、为什么建议删掉"空气"

Aspen 里的 `AIR` 是个**固定配比的混合物型组分**，但我们的流程需要**单独追踪氧的消耗**（氨氧化要算 O₂ 转化率）。所以进料必须用 **O₂ + N₂ 按 21 : 79（摩尔）** 分别给，而不是给一个 AIR。

`AIR` 留着不报错，但会在每条流股的组成列里多占一列，容易和 O₂/N₂ 重复计量。**建议删掉**（在 `组分` → `规格` 里选中那一行按 Delete）。

删不动也没关系——我不会用到它。
