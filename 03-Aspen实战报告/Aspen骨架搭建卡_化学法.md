# Aspen 骨架搭建卡（化学法 · 约 15 分钟建拓扑）

## 一、为什么要你亲手拖这一步

Aspen Plus 的 COM 自动化接口**只能读写已有模型的参数、运行和导出结果，不能创建模块与流股**（这是 Aspen 官方 API 的设计边界，不是配置问题）。我实测确认：

- ✅ 能连接 Aspen、新建/打开文件、**读写任意参数**、运行、导出结果
- ❌ 不能新增模块、新增流股、建立连接

所以分工是：**你在界面上把拓扑拖出来（15 分钟）；拖完保存后，其余全部由我自动完成**——填组分、设物性方法、写反应、填 30 条流股、填 14 个模块条件、设撕裂流、运行、调收敛、导出结果。

---

## 二、第一步：新建并保存

1. Aspen Plus V15 → `New` → `Blank Simulation`
2. **立刻** `File` → `Save As`，保存到：
   ```
   D:\<化工工作区>\NA-Chemical-10000t.apwz
   ```
3. `Setup` → `Specifications` → Units 选 `Metric Units`

### 中文界面名称对照（Aspen Plus 中文版）

| 我给的类型路径 | 中文界面里显示的名称 | 图形特征 |
|---|---|---|
| Mixers/Splitters → Mixer | 混合器/分流器 → **混合器** | 两个进口一个出口的箭头块 |
| Exchangers → Heater | 换热器 → **加热器** | 带热流箭头的方块 |
| Reactors → RStoic | 反应器 → **化学计量反应器** | 带反应箭头的釜形 |
| Columns → RadFrac | 塔 → **严格精馏** | 带冷凝器+再沸器的塔（部分版本译作"严格分馏"） |
| Columns → Extract | 塔 → **萃取** | 塔顶与塔底各一进口的液液塔 |
| Separators → Flash2 | 分离器 → **闪蒸2** | 立式罐，气相从顶出 |

**找不到模块时怎么办**：
1. 鼠标悬停在图标上，会浮出英文 ID（如 `RadFrac`）；
2. 或在 `模型库` 顶部的搜索框直接输英文名（`RadFrac`、`RStoic`、`Flash2`）；
3. 注意：中文界面只影响"面板显示名"，**不影响你要起的块 ID** —— 我认的是 `R-101`、`T-403` 这类名字。

**14 个模块的分布**：
- **加热器 Heater** 共 3 个：`E-101`、`E-104`、`E-201`
- **严格精馏 RadFrac** 共 4 个：`T-401`、`T-402`、`T-403`、`T-404`
- **化学计量反应器 RStoic** 共 3 个：`R-101`、`R-501`、`F-501`
- 其余各 1 个：混合器 `M-101`、严格精馏 `T-201`（吸收塔）、萃取 `T-301`、闪蒸2 `E-601`

> **不要摆**结晶器 C-601、离心机 M-601、干燥器 D-601 —— 缺溶解度数据，走手算。

## 六、之后我会自动做（你不用管）

1. 写入 17 个组分（含 CAS 号）
2. 设置分段物性方法（PR-BM / ELECNRTL / NRTL）
3. 定义 3 组反应：R-101 氨氧化、R-501 水解+副反应、F-501 中和
4. 填 30 条流股的温度/压力/流量/组成
5. 填 14 个模块条件：理论板数、进料位置、操作压力、回流比、转化率
6. 设撕裂流与收敛参数（Wegstein，迭代 50）
7. 运行 → 读 Control Panel → 迭代修正不收敛项
8. 导出结果并做物料平衡校核（与第 3 章表 3-1、表 3-3 对照）
9. 出报告：哪些收敛、哪些偏差大、下一步怎么调

## 七、常见搭错点（提前避免）

| 易错                       | 后果                      |
| ------------------------ | ----------------------- |
| 模块名不一致（如用 R101 而非 R-101） | 我的脚本找不到节点，全部失效          |
| T-201 用 RadFrac 但设了冷凝器   | 急冷塔是吸收塔，冷凝器应设 None      |
| R-501 摆成 RCSTR           | 缺动力学参数，必须用 RStoic       |
| E-601 只摆了 1 个却想模拟三效      | 先摆 1 个跑通，我再补 2 个 Flash2 |
| 流股没改名                    | 我按名字写，找不到就报错            |
