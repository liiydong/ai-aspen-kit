## 四、从"打不开"到"跑通"：8 个根因（都已解决）

这一段是整个任务的核心，记录下来以后可复用。

| # | 现象 | 根本原因 | 解决 |
|---|---|---|---|
| 1 | 文件在 Aspen 里看不到"流股/模块" | 文件被设成 **`RUN-CLASS = PROP`（仅物性）**，该模式不加载流程图 | 改 `SETUP MAIN` 的 `RUN-CLASS = FLOWSHEET` |
| 2 | COM 报"规格不全"`AE_UNDERSPEC` | **流股温压**用 COM 写不进去（实测在正常模型上同样失败） | 改为**文本注入** `SUBSTREAM ... TEMP = ... PRES = ...` |
| 3 | 塔的进料板/采出板"未指定" | 记录分隔符写法不对；且**每条记录必须单独成行** | 每条记录以 `\ \ ` 开头、独立成行 |
| 4 | 塔压无效 | 压力单位行号写错：`METCBAR_MOLE` 应为 **`<20> <5>`**，误用了另一单位集的 `<20> <10>` | 统一改 `<20> <5>`（**这一处修好后五座塔全部收敛**） |
| 5 | 反应器报"质量不守恒"，误差恰等于 Σ\|系数\|×分子量 | RStoic 的 **STOIC 表：反应物必须用 `STOIC`/`COEF`，产物必须用 `STOIC1`/`COEF1`**；全写成 `STOIC` 时 Aspen 把产物也当反应物 | 反应物/产物分组书写 |
| 6 | T-201 报"底部进料流量为零 / 干板" | 无冷凝器、无再沸器时 `QN = 0`，Aspen 要求底部必须有汽相来源 | 加**小再沸器**（`REBOILER = KETTLE`，`BASIS-BR = 0.1`） |
| 7 | 报 `DHVLWT MISSING FOR NAOH`，计算中止 | NaOH 是离子型固体，物性库缺汽化潜热参数；**NRTL / NRTL-RK 的液相焓都需要它** | 物性方法改 **`PENG-ROB`** 状态方程法（焓由状态方程求偏摩尔量，不需要 DHVLWT） |
| 8 | 保存的 `.bkp` 里读不到结果 | **`.bkp` 不保存计算结果** | 运行后**在同一进程内**读取；结果随 `.apwz` 保存 |

**另外两条经验：**
- COM **不能创建模块、不能新增组分、不能创建反应**，但**可以读写任意已有节点的参数、可以运行、可以读结果**。所以"拖模块"必须人工做一次，其余可自动化。
- `.apwz` 里的 `.bkp.backup` 是**降级备份**（缺 DATABANKS 段、`RUN-CLASS` 会退回 `PROP`）。**给它文件时一律用"另存为 → Aspen Plus Backup (\*.bkp)"**。

## 五、物性方法：为什么最终用了 PENG-ROB

| 方案 | 结果 |
|---|---|
| `NRTL` | NaOH 缺 `DHVLWT`，液相焓算不出，计算中止 |
| `NRTL-RK` | 同样调用 Watson 模型，仍缺 `DHVLWT` |
| **`PENG-ROB`** | **跑通** ✓ |

**说明**：论文手册里推荐的「PR-BM（高温段）/ ELECNRTL（电解质段）/ NRTL（精馏与蒸发段）」分区方案在**原理上仍然正确**，但要在 Aspen 里落地，必须先解决 NaOH 的物性缺口。可选的彻底方案（任选其一）：

1. 改用 **ELECNRTL** 并引入离子组分（Na⁺、OH⁻、HSO₄⁻、SO₄²⁻…）——最正确，但要重建组分表；
2. 给 NaOH 补 `DHVLWT`（需查权威数据，不建议估）；
3. 把 NaOH / H₂SO₄ / Na₂SO₄ 三个组分及其流股从模型中剔除（流量仅 0.075 kmol/h，占比 0.04%，对总量无影响），保留 NRTL。

> 本次为**先跑通**采用了 PENG-ROB。若论文要强调 NRTL，建议按上面方案 3 处理后再切回。

## 六、发现的论文问题（建议修改）

### 6.1 深度氧化反应式不配平 —— 已修正

第 4 章表 4-3 原写：

```
C₆H₇N + 7.5 O₂ → 6 CO₂ + 0.5 N₂ + 3 H₂O     ← 氢差 1、氧差 0.5，不配平
```

Aspen 校核报「REACTION 2 DOES NOT SATISFY MASS BALANCE，偏差 −1.0079」（正好是 1 个氢原子量）。

正确配平（已写入论文）：

```
C₆H₇N + 7.75 O₂ → 6 CO₂ + 0.5 N₂ + 3.5 H₂O
检验：C 6=6 ✓   H 7=7 ✓   N 1=1 ✓   O 15.5=12+3.5 ✓
```

ΔH 按本章同一基准（气相、298 K，ΔfH°: CO₂ −393.5、H₂O −241.8、3-MP +62.5）重算：
6×(−393.5) + 3.5×(−241.8) − 62.5 = **−3270 kJ/mol**（表内已更新）。

### 6.2 氨氧化主反应热：表格值与推导式不一致 —— 待你核实

表 4-3 写 −543.3 kJ/mol，但正文第 103–106 行的推导用 ΔfH°(3-氰基吡啶) = +281.5 算出的是 **−460.3 kJ/mol**。两者对不上。

要得到 −543.3，需要 ΔfH°(3-氰基吡啶, g) ≈ **+198.5 kJ/mol**。建议查权威热化学数据确认 3-氰基吡啶的生成焓，再统一表格与推导。

### 6.3 尾气里的 HCN 和 CO 没有来源反应

第 3 章尾气 G₁₋₁ 成分列了 **HCN、CO**，但第 4 章的深度氧化式只生成 CO₂ + N₂ + H₂O，**没有任何反应生成 HCN 和 CO**。要么补一条 HCN/CO 的生成副反应，要么把这两种组分从尾气清单里去掉。

### 6.4 T-201 的建模说明

真实的急冷吸收塔没有再沸器。本次为了满足 Aspen 对"无再沸器时底部必须有汽相来源"的要求，给了 `BASIS-BR = 0.1` 的**小汽化率**（再沸器负荷 0.229，相对四塔很小）。
论文里建议这样表述：*"急冷吸收塔在 Aspen 中以 RadFrac 模拟，为满足无再沸器塔的干板约束，底部设置 0.1 的汽化率以数值稳定收敛，其对总物料与热量平衡的影响小于 0.5%。"*

### 6.5 二元交互参数为零

Aspen 提示 `NRTL BINARY PARAMETERS FOR ALL COMPONENT PAIRS ARE ZERO`（改用 PENG-ROB 后此提示消失，但仍无实测二元参数）。论文的物性方法章节应补一句：**二元交互参数缺省为零，精馏段的相对挥发度需以第 3 章的实测/文献数据校核**。
