## 这个目录里的经验，浓缩成 10 条

如果只给你 10 句话，是这 10 句：

1. **Aspen 有两个环境**：`物性`(Properties) 里 F5 是算参数，`模拟`(Simulation) 里 F5 是跑流程。
   让程序在"模拟"环境做参数估算，会陷入「运行要求先有参数、参数要靠运行产生」的死循环。
2. **只用 `.bkp` 交付**。`.apwz` 是 ZIP，里面的 `.bkp.backup` 是**降级备份**——缺 `DATABANKS`，且 `RUN-CLASS` 可能退回 `PROP`。
3. **健康模型的判据**：`\Data` 下有 **25 个子节点**，且含 `Streams` / `Blocks` / `Flowsheet`。
   只有 8 个 → `RUN-CLASS = PROP` 了，流程图根本没加载。
4. **树路径里 `Binary Interaction` 和 `Molecular Structure` 带空格**。写成 `Binary` 会静默返回 `None`。
5. **bkp 文本注入的记录分隔符是单个 `\`**。参考文件里看到的 `\ \` 是行末换行符，照抄成一行会让**整段不解析**。
6. **每约 76 字符会折行**，会把 `BLOCK BLKID = "X"`、`? STREAM MATERIAL` 拆开 → 定位必须用容忍换行的正则，`str.find` 会失败。
7. **COM 不能建模块、不能加组分、不能写分子结构、不能写流股的 TEMP/PRES**。
   能建流股、能写模块参数、能写组分流量、能运行取数。**其余全靠文本注入。**
8. **`Run2()` 是异步的**：必须 `pythoncom.PumpWaitingMessages()` + 轮询 `IsRunning`，否则拿到全 `None`。
9. **判断参数有没有生效，看保存后文件里的 `UVAL` 条数**，不是 COM 的 `Output\CID1` —— 那个永远是 0 行，连出厂示例也是。
10. **`.bkp` 不保存计算结果**：必须"打开 → 运行 → 同一进程内读取/导出"。
