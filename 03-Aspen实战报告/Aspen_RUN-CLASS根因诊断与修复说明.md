## 一、结论先行

你的流程图**搭得完全正确**（14 个模块 + 29 条流股，一条不差）。
之前"打不开""COM 里读不到模块和流股"的根因，是文件里有一个字写错了：

> ### 根因：`RUN-CLASS = PROP`（仅物性运行类型）

Aspen 文件的 `SETUP MAIN` 段里有一个 `RUN-CLASS` 字段，决定这个文件按什么模式运行：

| 取值 | 含义 | 后果 |
|---|---|---|
| `FLOWSHEET` | **流程模拟**（正常） | 加载流程图，Blocks / Streams 都在 |
| `PROP` | **仅物性** | **根本不加载流程图**，Blocks / Streams 节点不存在 |

你的文件是 `PROP`，所以：

- Aspen 打开后 Data Browser 里**没有"流股""模块"两个文件夹**
- 通过 COM 读到的树只有 **8 个节点**（正常应为 **25 个**）
- 模块参数虽然能写（当时测过 R-101），但因为模块没实例化，写了也没意义
- 流股参数写不进去（报 `AE_UNDERSPEC` 规格不全）

## 四、还剩最后一个卡点：3 个组分加不进去

### 现象

文件里目前只有 **12 个组分**：

`3-MP(3-甲基吡啶)`、`NH3`、`O2`、`N2`、`H2O`、`3-CP(3-氰基吡啶)`、`4-CP`、`TOL(甲苯)`、`CO2`、`CO`、`HCN`、`AIR`

**缺 5 个**（其中 3 个是硬性必需）：

| CAS | 物质 | 用途 | 必需性 |
|---|---|---|---|
| 108-89-4 | 4-甲基吡啶 | 杂质来源 | 一般 |
| **98-92-0** | **烟酰胺** | **主产品** | **必需** |
| 59-67-6 | 烟酸 | 水解副产物 | 必需 |
| **1310-73-2** | **氢氧化钠** | **水解反应物** | **必需** |
| **7664-93-9** | **硫酸** | **中和剂** | **必需** |
| 7757-82-6 | 硫酸钠 | 中和副产 | 必需 |

### 为什么加不进去

我实测了很多次，结论是：

1. **COM 接口不能新增组分**（`Elements.Add` 报 `Aspen.Variable Access`，这是 Aspen 自身的限制）
2. **手工往 .bkp 文本里插组分可以生效**——但**很不稳定**：
   - `4-MP`、`NICOTINAMIDE`、`NICOTINIC-ACID` 稳定成功
   - `SODIUM-HYDROXIDE`、`SULFURIC-ACID`、`SODIUM-SULFATE-SOLID` 时好时坏
3. **真正的根因**：你的文件 **`DATABANKS` 段是空的**（正常文件应该有 `FILE-SYM-NAM = ( "APV150 PURE41" ... )` 这样的数据库清单）

   > `PROP` 模式下 Aspen 会把所有物性数据库都加载（所以之前测出的组分能解析）；
   > `FLOWSHEET` 模式下**只加载文件里声明过的数据库**——你的文件没声明，所以 NaOH、硫酸这类位于 INORGANIC / AQUEOUS / SOLIDS 库的组分就找不到了。

   我按参考模型补了数据库清单，结果反而更差（说明那串符号名是本机不适配的），所以**没有采用**。

### 唯一的可靠解法

**让 Aspen 自己保存一次**——Aspen 保存时会自动补齐 `DATABANKS` 段和全部流段。之后组分、物性方法、反应、流股参数我都能全自动写入。
