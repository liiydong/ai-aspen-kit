## 一、瑞邦对齐评估（含最终结论）

### 1.1 两家实际路线对照

| | 安徽瑞邦（验收报告 [1]） | 河北冠润（环评 [2]） |
|---|---|---|
| 3-甲基吡啶来源 | 外购 | **自建 MPDA→3-甲基哌啶→3-甲基吡啶** |
| 提纯 3-CP | **萃取 + 精馏**（两步串联） | 精馏 |
| 萃取 | **甲苯逆流萃取，萃取率 >99.5%**，甲苯相 3-CP 约 35% | 环评未提萃取 |
| 精馏 | **四塔**：甲苯塔 → 3-CP 塔1（脱 4-CP）→ 4-CP 塔 → 3-CP 塔2（产品），收率 98% | 精馏提纯 |
| 水解 | **酶法（生物催化）** | 环评未写酶法 |

**关键判断：瑞邦的前半段（一路到 99.8% 的 3-CP）与水解方式无关**——水解发生在拿到纯 3-CP 之后。所以化学法版完整照搬瑞邦前半段，是站得住的；两版论文的差别只在最后一步。

瑞邦四塔实测参数 [1]：

| 瑞邦实际塔 [1] | 塔顶温度 / 压力 | 本设计对应塔 |
|---|---|---|
| 甲苯精馏塔 | **70 ℃ · 0.24 bar** | T-401 脱甲苯塔 |
| 3-氰基吡啶精馏塔 1（脱 4-CP） | **155 ℃ · 0.26 bar** | 本设计无直接对应（见 1.3）|
| 4-氰基吡啶精馏塔 | **148.8 ℃ · 0.4 bar** | T-403 脱 4-CP 塔 |
| 3-氰基吡啶精馏塔 2（产品） | **153.5 ℃ · 0.3 bar** | T-404 产品塔 |

### 1.2 评估中查出的真实设计漏洞

**原设计里的 T-402「脱水塔」是多余的。**

瑞邦四塔中**没有脱水塔**——水在萃取之前的吸收/蒸发段就已降到 35%，萃余水相直接送废水，**有机相基本不带水**[1]。我们原来的流程在萃取塔未修好之前把水错带进了甲苯相，于是多摆了一座 T-402 来"补漏"。

萃取塔按 99.5% 模拟后实测：**进入有机相的水只有 2.1 kg/h** —— T-402 完全无料可脱。

### 1.3 最终结论：对齐的是"数据"，不是"塔的表号"

执行后的事实是：

| 本设计塔 | 实际职责 | 塔压（取瑞邦实测值 [1]） |
|---|---|---|
| T-401 | 脱甲苯 | 0.24 bar ✓ 与瑞邦甲苯塔一致 |
| **T-402** | **脱轻组分（未反应 3-MP + 残甲苯）** | 0.26 bar ✓ 与瑞邦 3-CP 塔1 同压 |
| T-403 | 脱 4-CP | 0.40 bar ✓ 与瑞邦 4-CP 塔一致 |
| T-404 | 3-CP 产品 | 0.30 bar ✓ 与瑞邦 3-CP 塔2 一致 |

也就是说：**四座塔的压力全部对齐瑞邦实测值（改动最小、收益最大），塔的分工有三座与瑞邦一一对应**；唯一的差别是第二塔——瑞邦的"3-CP 塔1"做 4-CP 预分离，而本设计的 T-402 做**未反应 3-MP 与残甲苯的脱除**。

**这个差别是必要的，不是缺陷**：本设计里未反应的 3-MP（35.9 kg/h）会随吸收液一路带到精制工段，必须在进入 4-CP 分离前脱掉，否则产品纯度上不去（实测：不脱 3-MP 时产品纯度只有 97.1%，脱掉后达 99.97%）。瑞邦把这件事分别在吸收/蒸发段与萃取段解决了，本设计集中放在 T-402 完成。

> **对论文的处理（已执行）**：T-402 更名为"脱轻组分塔"并改写职责描述，四塔压力标注为引自瑞邦实测值 [1]。第 2、4、5、7 章已同步。

## 二、二元交互参数攻关（我自己补上了）

### 2.1 一个必须先讲的坑：文件里出现了重复段落

攻关过程中我发现：**Aspen 只读文件里的第一份块段落，而我的文本修改写进了第二份**，导致 T-401 的采出比、塔压等参数改了却毫无效果（回读 Aspen 内存仍是原值）。

根因是一个脚本索引 bug 把文件插成了 2 倍大小（同一段落出现两份）。**检查方法**：统计 `? BLOCK RADFRAC` 出现次数应为 5、`"T-401"` 段落应为 1。修正后所有参数回读全部正确：

```
T-401 D:F = 0.659   BASIS_RR = 3.0   PRES1 = 0.24
T-402 PRES1 = 0.26   T-403 PRES1 = 0.40   T-404 PRES1 = 0.30
```

> 教训：改 bkp 后**必须回读 Aspen 内存里的参数值**，不能只看文件写没写进去。

### 2.2 攻关路线与结果（5 条）

| # | 路线 | 结果 |
|---|---|---|
| 1 | 补 `DATABANKS` 的 `FILE-SYM-NAM` 清单 | ❌ 反而报 `MW MISSING FOR COMPONENT`，组分解析被破坏 |
| 2 | 换预测型物性方法 `UNIFAC` | ❌ 报 `UFGRP MISSING FOR COMPONENT 3-CP` |
| 3 | 换预测型物性方法 `UNIF-LL` | ❌ 同上（数据库无 3-CP 的 UNIFAC 基团）|
| 4 | 手工插入 NRTL 数值 | ⚠️ 可插入，但只解决单对组分 |
| 5 | **在 NRTL 参数段补 `BDBANK` 检索清单** | ✅ **成功** |

**正确写法**（抄自 Aspen 自带 `Conceptual Model Example.bkp` / `ICPEbegin.bkp` 的原生格式）：

```
PROP-LIST PARAMNAME = NRTL SETNO = 1 UNITROW = 0 TUNITROW = 22 TUNITLABEL = F \
  BDBANK = ( "APV150 VLE-RK" "APV150 VLE-IG" "APV150 LLE-ASPEN" "APV150 VLE-LIT" "APV150 VLE-HOC" ) \
  ESTIMATE = NO NEL = 12 \
```

效果（决定性改善）：萃取塔第一次真正**两相分层**——甲苯在水相溶解度 8.05 kg/h（0.4 wt%）、水在甲苯相 13.1 kg/h（0.24 wt%），量级完全正确。

### 2.3 客观边界：3-氰基吡啶没有液液平衡数据

Aspen 数据库里有水-甲苯参数（所以两相能分开），**没有 3-氰基吡啶的 LLE 数据**。严格 LLE 算出的分配系数偏小（有机相/水相 ≈ 0.42），萃取率仅 **50.4%**，且与溶剂比、级数无关（做过扫描验证：级数 8→16、循环甲苯量提高均纹丝不动）→ 属**热力学数据缺失**，非操作参数问题。

**处理**：按瑞邦实测「萃取效率大于 99.5%」[1]，把 T-301 由 `Extract` 改为 `Sep`（组分分离器，按指定分离率模拟）。**答辩时请照实说明是数据库缺数据，工业上该萃取率是实测值 [1]。**

### 2.4 改块类型必须同步改三处（供以后参考）

改成 `Sep` 时漏一处就报错，**而且报错信息具有误导性**：

| # | 位置 | 修改内容 |
|---|---|---|
| 1 | 文件头的块实例注册表 | `T-301\nExtract\nBuilt-In\nEXTRACT\n` → `T-301\nSep\nBuilt-In\nSEP\n` |
| 2 | `FLOWSHEET GLOBAL` 段 | `BLKTYPE = "EXTRACT" MDLTYPE = "Extract"` → `"SEP"/"Sep"`，且**端口全改 M0-1**（SEP 块进出料同一端口，不像 EXTRACT 用 M0-1/M1-2/M2-3）|
| 3 | 块段落 | `? BLOCK SEP "T-301" ? … PARAM PARAM-STREAM = "S-113" SUBSTREAM = MIXED COMPS = "H2O" FRACS = 0.999 <0> <0> / …` |

- 只改第 2 处会报「**R-101 有流程但无块段落**」——看似无关，实为块类型不匹配的连锁报错；
- 块段落**必须按约 76 字符换行**；写成一整行（700+ 字符）时解析器会吞掉后续段落，同样报成 R-101 错。

**T-301 的分离率设定**：

| 组分 | 去萃余水相 S-113 的分率 | 依据 |
|---|---|---|
| H₂O | 0.999 | 水相 |
| 甲苯 | 0.0005 | 溶解度（实测 1.13 kg/h）|
| 3-CP / 4-CP / 3-MP / 4-MP | **0.005** | **萃取率 99.5%** [1] |
| NH₃ | 0.99 | 极性随水相 |
| HCN | 0.50 | 两相分配估计 |
| O₂/N₂/CO₂/CO | 0.99 | 溶解气随水相（消除 T-401 热平衡报错）|

## 三、全塔标定执行记录

### 3.1 T-401 脱甲苯塔

**问题**：原 D:F = 0.995 不合理 → 塔顶跑到 −47 ℃、甲苯只回收 60%，2251.8 kg/h 甲苯随塔釜进精馏段。

**分析**：T-401 是"塔顶甲苯 / 塔釜 3-CP"的清晰分割，**D:F 应等于进料中甲苯的摩尔分率**。进料 S-114 中甲苯 24.46 kmol、3-CP 12.11 kmol、其他 0.58 kmol，合计 37.15 kmol → **D:F = 24.46/37.15 = 0.659**。

**结果**：

| 项 | 值 |
|---|---|
| 塔顶温度 / 塔底温度 | **53.2 ℃ / 145.4 ℃** |
| 回流比 | 3.0 |
| 塔顶甲苯 S-115 | 2244.0 kg/h |
| 塔釜残留甲苯 S-116 | 9.54 kg/h（回收 99.3%）|
| 冷凝器 / 再沸器 | −1032 kW / 1124 kW |

> **验证点**：甲苯在 0.24 bar 下的沸点为 52.5 ℃，模拟值 53.2 ℃——说明物性方法与压力设定正确。瑞邦实测塔顶 70 ℃ [1] 略高，推测为其测点位于塔内不同位置或操作压力略有差异，已在报告中注明。

### 3.2 甲苯循环量的处理（工程决策）

**问题**：甲苯是闭路循环，其循环量在数值上由"补充量 = 损失量"决定，而损失量本身又随循环量变化 → 是一阶积分环节，Aspen 收敛到的库存值与初值有关、不可控。多轮尝试（调整补充量与 T-401 采出比）均无法稳定得到设计值。

**处理**：按工程上通行的做法，**把甲苯循环回路展开为一次通过**——S-111 以设计循环量 **24.47 kmol/h（2254.7 kg/h）** 甲苯作为进料加入萃取塔，T-401 塔顶 S-115 为回收甲苯。等价于实际装置的甲苯循环，且物料平衡确定、可复现。

**结果**：萃取相 S-114 = **3559.6 kg/h（甲苯 2253.55、3-CP 1260.65 = 35.4%）**，甲苯循环量 **2244.0 kg/h** —— 与设计值 3469.1 kg/h、35%、2254.9 kg/h 分别偏差 **+2.6%、+0.4 个百分点、−0.5%**。

### 3.3 T-402 脱轻组分塔 + T-403 + T-404

**关键发现**：改完 T-401 后，产品只有 248 kg/h——因为 T-402 按原"脱水塔"的 D:F = 0.80 把 **1002.6 kg/h 的 3-CP 送进了塔顶死端**。

**处理**：

| 塔 | D:F | 回流比 | 职责 |
|---|---|---|---|
| T-402 | **0.040** | 15 | 脱未反应 3-MP（35.9 kg/h）与残甲苯（9.54 kg/h）|
| T-403 | 0.0050 | 18 | 脱 4-CP |
| T-404 | 0.9500 | 10 | 3-CP 产品 |

**产品纯度对比（说明 T-402 改职责的必要性）**：

| T-402 设定 | 产品 S-121 | 3-CP | 3-MP | 纯度 |
|---|---|---|---|---|
| D:F=0.006（仅脱甲苯）| 1235.1 kg/h | 1199.9 | 35.9 | **97.15%** ✗ |
| **D:F=0.040（脱甲苯+3-MP）** | **1196.7 kg/h** | **1196.4** | **0.00** | **99.97%** ✓ |
