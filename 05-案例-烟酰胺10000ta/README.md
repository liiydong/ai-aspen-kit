# 案例：烟酰胺 10000 t/a 全流程设计

## 这个案例讲的是什么

**工艺路线**（八步）：

```
3-甲基吡啶气相氨氧化 → 吸收 → 甲苯萃取 → 四塔精馏 → 化学水解
      → 中和 → 脱色 → 三效蒸发 → 结晶 → 离心 → 干燥
```

**核心成绩：**

| 指标 | 结果 |
|---|---|
| 模型规模 | **36 单元 / 61 流股 / 15 组分**，物性方法 NRTL |
| 模型状态 | Terminal / Severe / Errors **全为 0** |
| 总物料平衡 | 进 15006.04 kg/h = 出 15006.04 kg/h，偏差 **0.0000%** |
| 产品产量 | 1411.6 kg/h ≈ **10163.8 t/a**（超设计规模 1.6%） |
| 产品纯度 | **99.62 wt%** |
| 3-MP 单耗 | **916.9 kg/t**（设计值 936.89） |
| 全流程总收率 | **83.26%** |
| 反应器净移热 | **2.19 MW**（熔盐产 1.0 MPa 蒸汽 3.9 t/h） |

## ⭐ 为什么 `数据核对与订正说明.md` 最值得读

它不是"我做完了"的总结，而是**发现自己的错误并订正的过程**。里面记录了：

### 一处足以毁掉整篇结论的错误

**反应热的量纲错了：**

```
原写法：12.169 × 0.88 × 543.3 = 5817 kW
实际量纲：kmol/h × kJ/mol = MJ/h  →  1.62 MW
        被当成 kW 用，再 ×3.6  →  23880 MJ/h
        放热量被放大 3.6 倍
```

**连带后果 —— 全部翻转：**

| 指标 | 错误结论 | 订正后 |
|---|---|---|
| 熔盐产 1.0 MPa 蒸汽 | 11.8 t/h | **3.9 t/h** |
| 全装置蒸汽平衡 | **自给有余（富余 5.94 t/h）** | **缺口 2.21 t/h，需外购** |

> **一条量纲错误，把"这个工艺能自给蒸汽"变成了"这个工艺要外购蒸汽"。**
> 如果没发现，整篇论文的节能结论都是错的。

### 其他订正项（节选）

```bash
#   （单耗、收率、产汽量、换热负荷）
#
# 第 4 步：打开 .bkp 模型，重跑一次，确认 Terminal/Severe/Errors 全为 0
```

### ⚠️ 解析 Aspen xlsx 报告的三个陷阱

1. **每行被切成 A/B/C 三列** —— `A + B + C` 直接拼接即还原原行
2. **B→C 切点会吃掉一个空格** → 两个数值粘连（`13.9059` + `13.9059` = `13.905913.9059`）
   → 规则：**B 尾不是 `-` / `+` 时，在 B、C 之间补一个空格**
3. **组分名里的数字会污染取值**（`H2O` 的 2、`3-CP` 的 3）
   → 规则：**先剥离组分名/单位标签再取数值**

> 还有一个分页陷阱：**页首行的 `S-101 S-102 …` 才是可靠的分页标记**
> （`STREAM ID` 行会因 `S-104S-105` 粘连而丢 ID）。

## 模型的两处「等效建模」（如实说明，未掩盖）

| 单元 | 为什么不用严格模型 | 用了什么 |
|---|---|---|
| **T-301**（萃取塔） | 库中缺 3-CP 的液液平衡数据 | `Sep`（按实测分离率） |
| **T-403**（3-CP/4-CP 分离） | 相对挥发度 α≈1.05，且库中缺二元 VLE 数据 | `Sep`（4-CP 从塔顶采出作副产） |

另有两项未纳入模型：

- **离子组分**（NaOH / H₂SO₄ / Na₂SO₄，占 0.03%）—— 因 NRTL 焓参数不完整，按化学计量单独核算
- **亨利组分**（N₂/O₂/CO/CO₂/HCN）—— COM 无法设置，**必须经 GUI**（本案例的最终模型已由作者在 GUI 完成）

> **这四项都是"算不了就如实说"，而不是硬凑一个数。**
> 详见 [`../03-Aspen实战报告/`](../03-Aspen实战报告/) 里对应的报告。

## 二元交互参数：一个"数据从哪来"的诚实回答

模型里 `NRTL-1` 参数表**是空的**，但模型照样能跑 —— 因为缺失参数时 Aspen 按理想溶液处理。

作者做了**对照实验**来量化这个假设的影响：

| 指标 | 理想溶液 | 含 5 对真实参数 | 偏差 |
|---|---|---|---|
| 产品 S-209 | 1419.529 kg/h | 1419.256 kg/h | **−0.019%** |
| T-401 冷凝负荷 | −0.9258 | −0.9257 | **−0.007%** |
| S-114 温度 | 34.279 ℃ | 34.331 ℃ | +0.05 ℃ |
| Terminal/Severe/Errors | 0/0/0 | 0/0/0 | — |

**结论：全流程变化 < 0.02%，物料衡算结论不依赖该假设。**

那 5 对参数是从 **518 个 Aspen 自带 `.bkp` 示例文件**里筛出来的真实数据
（`H₂O–TOL` / `H₂O–NH₃` / `H₂O–CO₂` / `H₂O–HCN` / `O₂–H₂O`），
方法与来源文件见 [`../03-Aspen实战报告/Aspen二元交互参数_诊断与解决方案.md`](../03-Aspen实战报告/Aspen二元交互参数_诊断与解决方案.md)。
